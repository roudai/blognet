# Quickstart: 記事ページとトップページの移植

**Feature**: `002-posts`

## 手順

```sh
pnpm generate
pnpm verify          # 6ページと画像18枚の存在、移植元との同一性、広告の痕跡がないこと
pnpm verify:parity   # 本番(https://blog.roudai.net)との本文、リンク、画像、動画の比較(ネットワークが必要)
pnpm preview 4310    # ブラウザーで確認
```

## 確認(Spec の受け入れシナリオ)

1. **US1**: `pnpm verify:parity` が、6ページすべてで成功する(記録済みの修正だけが差分として表示される)。`/post-37/`(末尾のスラッシュあり)も開ける。
2. **US2**:
   - `/post-37` を直接開き、画像10枚、動画5件、ツイート1件が表示される。動画を再生できる。
   - `/post-535` を直接開き、ツイート6件が埋め込みとして表示される。
   - トップページから、再読み込みなしで `/post-535`、`/post-37` へ移動し、ツイートが表示される。
   - `/post-700` を幅 1280px と狭い幅で開き、写真8枚の幅と位置が現行と同じ。
3. **US3**: `/` に見出しと5件のリンクが現行と同じ順序で並び、それぞれの記事へ移動できる。
4. **US4**: spec.md の表の修正後の表記が、新サイトに表示される。

## 実施結果(2026-11-22)

- `pnpm lint`、`pnpm typecheck`、`pnpm generate`、`pnpm verify` が成功した。
- `pnpm verify:parity` が6ページすべてで成功した(記録済みの修正4件のみ)。
- US2 は、generate の出力(preview)と dev の両方で確認した。dev ではハイドレーションの警告が出なかった。
- 幅 1280px の `/post-37` と、幅 500px の `/post-700` で、画像、動画、ツイートの大きさと横の位置が現行と一致した(縦の位置の差は、現行の自動広告の分のみ)。
